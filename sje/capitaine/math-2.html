2 — Développements limités (DL), suites, séries : comprendre et savoir expliquer

Définitions (version simple, expliquable à l’oral)
  • Suite \((u_n)\) : une liste de valeurs rangées : \(u_0, u_1, u_2,\dots\) où \(n\) est le “numéro” (le rang).
  • Terme \(u_n\) : la valeur de la suite au rang \(n\) (ex : \(u_3\) = 4ᵉ valeur si on commence à \(u_0\)).
  • Récurrence : formule qui donne \(u_{n+1}\) à partir de \(u_n\) (ex : “à chaque étape on transforme la valeur précédente”).
  • Série \(\sum u_n\) : une somme “qui continue” ; on regarde les sommes partielles \[ S_N=u_0+u_1+\cdots+u_N. \] La série converge si \(S_N\) se stabilise quand \(N\to\infty\).
  • Développement limité (DL) en \(a\) : une approximation polynomiale de \(f(x)\) quand \(x\) est proche de \(a\). On écrit (à l’ordre \(n\)) : \[ f(x)=c_0+c_1(x-a)+c_2(x-a)^2+\cdots+c_n(x-a)^n + o\big((x-a)^n\big). \]
  • Ce que veulent dire les symboles :
    • \(a\) : le point autour duquel on approxime (souvent \(a=0\)).
    • \(x\) : la variable ; “\(x\to a\)” signifie “\(x\) se rapproche de \(a\)”.
    • \(n\) : l’ordre (jusqu’à quelle puissance on garde).
    • \(c_k\) : des nombres (coefficients) propres à la fonction (ils ne changent pas).
    • \(o((x-a)^n)\) : le “reste” : c’est plus petit que \((x-a)^n\) quand \(x\to a\). Le o est une lettre (pas le chiffre 0).
Théorie (pour comprendre vite)
  • À quoi sert un DL ? À remplacer une fonction compliquée par un polynôme près d’un point, surtout pour calculer une limite.
  • À quoi sert une suite ? À décrire une grandeur qui change “étape par étape” (itérations, régulation, amortissement…).
  • À quoi sert une série ? À additionner une infinité de termes ; au concours on tombe surtout sur la série géométrique et les sommes télescopiques.
DL : règles pratiques (avec explication)
  • Unicité : à un ordre donné, il n’y a qu’une seule approximation correcte (les \(c_k\) sont imposés).
  • Somme : si \(f=g+h\), tu fais le DL de \(g\) et de \(h\), puis tu additionnes les polynômes (même \(a\), même ordre).
  • Produit : tu multiplies les polynômes, puis tu gardes seulement les termes jusqu’à l’ordre choisi.
  • Choisir l’ordre : si le numérateur commence à l’ordre \(x^2\), il faut au moins un DL à l’ordre 2, etc. (on veut voir le premier terme non nul après simplification).
Méthode “limite avec DL” (simple)
  1. Repérer le point (\(x\to 0\) = le plus fréquent).
  2. Remplacer par le DL correspondant.
  3. Simplifier / factoriser.
  4. Lire la limite sur le premier terme restant.
Fonction DL en 0 (à connaître) Quand l’utiliser
\(\mathrm{e}^x\) \(\mathrm{e}^x=1+x+\frac{x^2}{2}+o(x^2)\) \(\mathrm{e}^x-1\), limites exp près de 0.
\(\ln(1+x)\) \(\ln(1+x)=x-\frac{x^2}{2}+\frac{x^3}{3}+o(x^3)\) \(\ln(1+x)\) quand \(x\to 0\).
\(\sin x\) \(\sin x=x-\frac{x^3}{6}+o(x^3)\) Petits angles / limites trigonométriques.
\(\cos x\) \(\cos x=1-\frac{x^2}{2}+o(x^2)\) Quand tu vois \(1-\cos x\).
Suites : “formes qui tombent” (et comment les reconnaître)
  • Arithmétique : on ajoute toujours la même quantité : \[ u_{n+1}=u_n+r \Rightarrow \boxed{u_n=u_0+nr}. \]
  • Géométrique : on multiplie toujours par la même quantité : \[ u_{n+1}=q\,u_n \Rightarrow \boxed{u_n=u_0q^n}. \]
  • Affine (très fréquent) : “on garde une partie + on ajoute” : \[ u_{n+1}=a u_n+b. \] Idée : si \(|a|<1\), la suite se stabilise vers une valeur \(\ell\).
    Valeur d’équilibre : \(\ell=a\ell+b\Rightarrow \boxed{\ell=\frac{b}{1-a}}\).
    Formule pratique : \(\boxed{u_n=\ell+(u_0-\ell)a^n}\) donc \(u_n\to \ell\).
Séries : l’essentiel
  • Test “simple” : si \(u_n\) ne tend pas vers 0, la série \(\sum u_n\) diverge.
  • Série géométrique : \[ \sum_{n=0}^{\infty} q^n=\frac{1}{1-q}\quad (|q|<1). \] Et \[ \sum_{n=1}^{\infty} q^n=\frac{q}{1-q}\quad (|q|<1). \] Reconnaissance : tu arrives à écrire le terme sous la forme \(A\cdot q^n\).
  • Télescopique : si \(u_n=v_n-v_{n+1}\), alors \[ \sum_{n=0}^{N}u_n=v_0-v_{N+1}. \]
Exercice type (guidé, style annale)

A — DL / limite
Calculer : \[ L=\lim_{x\to 0}\frac{\ln(1+x)-x}{x^2}. \] Ce que représentent les termes : \(x\to 0\) = “\(x\) très petit”, \(\ln(1+x)\) ≈ “log près de 1”.

Correction A
DL en 0 : \(\ln(1+x)=x-\frac{x^2}{2}+o(x^2)\).
Donc \(\ln(1+x)-x=-\frac{x^2}{2}+o(x^2)\).
\[ \frac{\ln(1+x)-x}{x^2}=-\frac12+o(1)\Rightarrow \boxed{L=-\frac12}. \]

B — Suite affine (régulation)
On modélise une correction automatique : \[ u_{n+1}=0{,}9u_n+5,\qquad u_0=0. \] 1) Trouver la valeur d’équilibre \(\ell\). 2) Donner \(u_n\). 3) Donner \(\lim u_n\).

Correction B
\(\ell=0{,}9\ell+5\Rightarrow 0{,}1\ell=5\Rightarrow \boxed{\ell=50}\).
\[ \boxed{u_n=\ell+(u_0-\ell)0{,}9^n=50-50\cdot 0{,}9^n}. \] Comme \(0{,}9^n\to 0\), \(\boxed{\lim u_n=50}\).

C — Série géométrique
Calculer : \[ S=\sum_{n=1}^{\infty}\frac{2^n}{5^n}. \] Astuce : essayer d’obtenir \((\frac{2}{5})^n\).

Correction C
\(\dfrac{2^n}{5^n}=\left(\dfrac{2}{5}\right)^n\). Donc \(q=\dfrac{2}{5}\) et \(|q|<1\) → convergence.
\[ S=\sum_{n=1}^{\infty}q^n=\frac{q}{1-q} =\frac{\frac{2}{5}}{1-\frac{2}{5}} =\boxed{\frac{2}{3}}. \]
