Chimie — C) Chimie organique : hydrocarbures, polymérisation, nomenclature

Chimie — C) Chimie organique (hydrocarbures, familles, polymérisation)

Définitions
  • Chimie organique : chimie des composés du carbone (souvent avec H, O, N, halogènes…).
  • Hydrocarbure : composé contenant seulement C et H (ex : CH₄, C₂H₆).
  • Alcane : hydrocarbure saturé (liaisons simples C–C) ; formule CnH2n+2.
  • Alcène : hydrocarbure insaturé avec au moins une double liaison C=C ; formule CnH2n.
  • Alcyne : hydrocarbure insaturé avec au moins une triple liaison C≡C ; formule CnH2n−2.
  • Aromatique : famille à cycle stable avec électrons délocalisés (ex : benzène C₆H₆).
  • Saturé / insaturé : saturé = liaisons simples ; insaturé = présence de double/triple liaison (plus réactif).
  • Isomères : même formule brute, organisation différente (propriétés parfois très différentes).
  • Polymérisation : réaction où des monomères s’assemblent en longues chaînes (polymères).
  • Monomère : petite molécule répétée (ex : éthylène C₂H₄).
  • Polymère : macromolécule (ex : polyéthylène (C₂H₄)n).
  • CH₄ : méthane (alcane), gaz naturel, très inflammable.
  • C₂H₆ : éthane (alcane), combustible.
  • C₃H₈ : propane (alcane), GPL, combustible.
  • C₂H₄ : éthylène/éthène (alcène), monomère du polyéthylène.
  • C₂H₂ : acétylène/éthyne (alcyne), très inflammable.
  • C₆H₆ : benzène (aromatique), inflammable et toxique.
  • Combustion complète : formation CO₂ + H₂O (si assez de O₂).
  • Combustion incomplète : manque de O₂ → CO (toxique) + suies.
Théorie (zéro base → ce qu’il faut comprendre)
  • 1) Hydrocarbures = énergie : ces molécules contiennent beaucoup de liaisons C–H et C–C. Leur oxydation par O₂ libère beaucoup d’énergie → combustibles.
  • 2) Saturé vs insaturé :
    • Alcanes (CH₄, C₂H₆, C₃H₈) : liaisons simples, plus “stables”, combustibles usuels.
    • Alcènes / alcynes (C₂H₄, C₂H₂) : double/triple liaison → plus réactifs ; base de la polymérisation.
    • Aromatiques (benzène) : cycle stable ; propriétés toxiques à retenir ; inflammable.
  • 3) Nomenclature ultra-rapide : méth- (1 C), éth- (2 C), prop- (3 C) ; suffixes : -ane, -ène, -yne.
  • 4) Polymérisation (exemple clé) :
    • Éthylène C₂H₄ → polyéthylène : \(n\,C_2H_4 ightarrow (C_2H_4)_n\).
    • Terrain : les plastiques brûlent ; selon le polymère, fumées et gaz toxiques possibles (CO, HCl si PVC…).
  • 5) Pourquoi la combustion incomplète est dangereuse ? Si l’air manque (local confiné), le carbone n’est pas totalement oxydé : formation de CO (gaz très toxique, incolore) + fumées.
Équations pratiques
  • Combustion CH₄ : CH₄ + 2 O₂ → CO₂ + 2 H₂O
  • Combustion C₃H₈ : C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O
  • Polymérisation : n C₂H₄ → (C₂H₄)n
  • Formules générales : alcane CnH2n+2, alcène CnH2n, alcyne CnH2n−2
  • Lettres : n (sans unité), m (g), M (g·mol⁻¹), n(mol)
Exercice type (quantité d’O₂, appliqué)

Combustion complète du propane : C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O.
On brûle m = 22 g de propane (M(C₃H₈)=44 g·mol⁻¹).

1) Calculer n(C₃H₈).
2) Calculer n(O₂) consommée.
3) Phrase terrain : pourquoi un manque d’O₂ augmente la toxicité ?

Correction :
1) n = m/M = 22/44 = 0,50 mol.
2) n(O₂)=5×0,50=2,5 mol.
3) Manque d’O₂ → combustion incomplète → formation de CO toxique + fumées.
