4 — Dérivation, intégration : définitions et applications

Définitions
  • Dérivée \(f'(x)\) : pente de la tangente ; mesure la variation instantanée.
  • Point critique : \(x\) tel que \(f'(x)=0\) (ou \(f'\) non définie) dans le domaine.
  • Primitive : fonction \(F\) telle que \(F'(x)=f(x)\).
  • Intégrale : \(\int_a^b f(x)\,dx\) représente une aire algébrique entre \(a\) et \(b\).
  • Extremum : maximum/minimum local, souvent en point critique.
  • Convexité : liée au signe de \(f''(x)\) (utile mais pas toujours exigé).
Théorie
  • Variations : si \(f'(x)>0\) alors \(f\) est croissante ; si \(f'(x)<0\) alors décroissante.
  • Extremum : un changement de signe de \(f'\) autour d’un point critique indique un max ou un min.
  • Intégration : on reconnaît des primitives usuelles, puis on applique \(\int_a^b f=F(b)-F(a)\).
  • Application typique : optimisation (minimiser un coût / maximiser un débit), et calcul d’énergie/quantité cumulée via une intégrale.
Équations pratiques
  • Dérivées : \((x^n)'=nx^{n-1}\), \((\mathrm{e}^x)'=\mathrm{e}^x\), \((\ln x)'=\dfrac{1}{x}\) (pour \(x>0\))
  • Règles : \((uv)'=u'v+uv'\), \(\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^2}\)
  • Primitives : \(\int x^n dx=\dfrac{x^{n+1}}{n+1}+C\) (si \(n\neq -1\)), \(\int \dfrac{1}{x}dx=\ln|x|+C\)
  • \(\int \mathrm{e}^x dx=\mathrm{e}^x+C\)
  • Intégrale : \(\int_a^b f(x)\,dx=F(b)-F(a)\)
  • Lettres : \(n\in\mathbb{N}\), \(C\in\mathbb{R}\), \(a<b\).
Exercice type

Soit \(f(x)=x+\dfrac{4}{x}\) définie sur \(]0,+\infty[\).
1) Trouver le minimum de \(f\). 2) Calculer \(\int_1^2 (x^2+1)\,dx\).

Correction :
1) \(f'(x)=1-\dfrac{4}{x^2}\). Résoudre \(f'(x)=0\) : \(1=\dfrac{4}{x^2}\Rightarrow x^2=4\Rightarrow x=2\) (car \(x>0\)).
Signe : pour \(0<x<2\), \(x^2<4\Rightarrow \frac{4}{x^2}>1\Rightarrow f'(x)<0\) ; pour \(x>2\), \(f'(x)>0\).
Donc minimum en \(x=2\) : \(f(2)=2+\dfrac{4}{2}=2+2=4\). \(\boxed{f_{\min}=4}\).

2) Primitive : \(\int (x^2+1)\,dx=\dfrac{x^3}{3}+x\).
\(\int_1^2 (x^2+1)\,dx=\left(\dfrac{8}{3}+2\right)-\left(\dfrac{1}{3}+1\right)=\left(\dfrac{8}{3}-\dfrac{1}{3}\right)+(2-1)=\dfrac{7}{3}+1=\dfrac{10}{3}\).
\(\boxed{\int_1^2 (x^2+1)\,dx=\dfrac{10}{3}}\).
