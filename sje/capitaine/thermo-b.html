Thermo — Dilatations : solides, liquides, gaz

Définitions
  • Dilatation : variation de dimensions d’un corps quand sa température varie.
  • Dilatation linéaire : variation de longueur ΔL d’un solide.
  • Dilatation volumique : variation de volume ΔV (liquides et gaz surtout, mais aussi solides).
  • Coefficient de dilatation linéaire (α) : constante qui relie ΔL à ΔT pour un solide (K⁻¹).
  • Coefficient de dilatation volumique (β) : constante qui relie ΔV à ΔT (K⁻¹).
Théorie (court)
  • Solides : on utilise souvent la longueur (dilatation linéaire).
  • Liquides : volume principalement.
  • Gaz : variation importante ; souvent traité avec loi des gaz parfaits (fiche 6).
Équations pratiques
  • Solide : ΔL = α L₀ ΔT
  • Volumique : ΔV = β V₀ ΔT
  • Lettres : L₀ (m), ΔL (m), V₀ (m³), ΔV (m³), ΔT (K), α,β (K⁻¹)
Exercice type

Une barre de longueur L₀ = 2,0 m, α = 1,2×10⁻⁵ K⁻¹, subit un échauffement de ΔT = 50 K. Calculer ΔL.

Correction :
ΔL = α L₀ ΔT = 1,2×10⁻⁵ × 2,0 × 50 = 1,2×10⁻⁵ × 100 = 1,2×10⁻³ m = 1,2 mm.
Exercice type (dilatation volumique)

Lors d’un feu, un fût métallique contient V₀ = 200 L d’un liquide. Le liquide a un coefficient de dilatation volumique β = 7,0×10⁻⁴ K⁻¹. La température augmente de T₁ = 20 °C à T₂ = 80 °C.

1) Calculer l’augmentation de volume ΔV du liquide.
2) En déduire le volume final V₂.

Données / conversions :
ΔT = T₂ − T₁ (en K, même valeur qu’en °C).
1 L = 1,0×10⁻³ m³.

Correction :
ΔT = 80 − 20 = 60 K.
Formule : ΔV = β V₀ ΔT.

Conversion : V₀ = 200 L = 200×10⁻³ m³ = 0,200 m³.

ΔV = 7,0×10⁻⁴ × 0,200 × 60 = 7,0×10⁻⁴ × 12 = 8,4×10⁻³ m³.

Retour en litres : 8,4×10⁻³ m³ = 8,4 L.

Volume final : V₂ = V₀ + ΔV = 200 L + 8,4 L = 208,4 L.
