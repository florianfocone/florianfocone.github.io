Thermo — Principes 1 & 2 : U, H, S + gaz parfait + système divariant

Définitions
  • Système : portion de matière étudiée, séparée de l’extérieur par une frontière réelle ou imaginaire.
  • Système fermé : système qui n’échange pas de matière avec l’extérieur (mais peut échanger Q et W).
  • Énergie interne (U) : énergie stockée dans le système liée aux phénomènes microscopiques (agitation, interactions).
  • Chaleur (Q) : énergie échangée à cause d’une différence de température (Q > 0 si le système reçoit).
  • Travail (W) : énergie échangée par action mécanique (W > 0 si l’extérieur fournit du travail au système).
  • Système isolé : système sans échange de chaleur ni de travail avec l’extérieur (Q=0 et W=0).
  • Enthalpie (H) : fonction d’état définie par H = U + pV.
  • Entropie (S) : fonction d’état qui quantifie l’évolution possible d’un système (dans un système isolé, elle ne diminue pas).
  • Transformation réversible : transformation idéale sans dissipation, inversable en repassant par les mêmes états.
  • Transformation irréversible : transformation réelle avec dissipation, non inversable sans modifier l’extérieur.
  • Gaz parfait : modèle vérifiant l’équation d’état pV = nRT.
  • Système divariant : système dont l’état est fixé par deux variables indépendantes (pour un gaz parfait à n constant : choisir p et T fixe V).
Théorie (étoffée, sans blabla)
  • Premier principe (système fermé) : la variation d’énergie interne vient des échanges avec l’extérieur : ΔU = Q + W (convention de cette fiche : Q>0 si reçu, W>0 si travail reçu).
  • Travail de pression (piston, pression extérieure constante) : W = −pext ΔV. Une compression donne ΔV<0 donc W>0, une détente donne ΔV>0 donc W<0.
  • Cas importants :
    • Isochore (V constante) : ΔV=0 ⇒ W=0 ⇒ ΔU = Q.
    • Adiabatique : Q=0 ⇒ ΔU = W.
    • Isolé : Q=0 et W=0 ⇒ ΔU = 0.
  • Deuxième principe : il existe une fonction d’état S telle que, pour un système isolé : ΔS ≥ 0. L’égalité correspond à une transformation réversible, l’inégalité stricte à une irréversibilité.
  • Écriture pratique du second principe :
    • Réversible : dS = δQrev / T.
    • Irréversible : ΔS = Q/T + Scréée avec Scréée > 0 (production d’entropie).
  • Gaz parfait, état divariant : pour n constant, p, V, T ne sont pas indépendantes car pV = nRT. Il suffit donc de fixer deux variables (par exemple p et T) pour connaître la troisième (V).
  • Transformations usuelles (n constant) :
    • Isotherme (T constante) : pV = constante.
    • Isobare (p constante) : V/T = constante.
    • Isochore (V constante) : p/T = constante.
Équations pratiques
  • Premier principe : ΔU = Q + W
  • Travail de pression (pext constante) : W = −pext ΔV
  • Deuxième principe (isolé) : ΔS ≥ 0
  • Réversible : dS = δQrev/T
  • Gaz parfait : pV = nRT
  • Transformations usuelles (n constant) : pV = cste (T cste), V/T = cste (p cste), p/T = cste (V cste)

Exercice type (plus complet et plus dur, appliqué)

Contexte pompier : on utilise un volume d’air pour gonfler un coussin de levage. On modélise l’air comme un gaz parfait avec n = 1,0 mol. Le gaz est en contact avec un environnement qui maintient la température constante à T = 300 K.

État initial : V₁ = 10 L.
État final : V₂ = 20 L (détente).

Données : R = 8,31 J·mol⁻¹·K⁻¹ ; ln(2) ≈ 0,693 ; 1 L = 10⁻³ m³.

A) Détente réversible isotherme
1) Calculer p₁ et p₂.
2) Montrer que ΔU = 0 (gaz parfait isotherme) et en déduire la relation entre Q et W.
3) Calculer le travail reçu par le gaz : W = −nRT ln(V₂/V₁).
4) Calculer ΔSsystème pour cette transformation : ΔS = nR ln(V₂/V₁).
5) Conclure sur ΔStotal (système + environnement) pour une transformation réversible.

B) Détente irréversible isotherme (pertes)
On suppose que, pour la même variation d’état (mêmes V₁, V₂, T), le gaz ne fournit à l’extérieur qu’un travail de 1200 J (donc avec la convention de la fiche : W = −1200 J).
6) Calculer Q puis ΔSenvironnement et ΔStotal. Interpréter avec le deuxième principe.

Correction :
A1) p = nRT/V.
V₁ = 10 L = 0,010 m³ ⇒ p₁ = (1,0×8,31×300)/0,010 = 2493/0,010 = 2,49×10⁵ Pa ≈ 2,49 bar.
V₂ = 20 L = 0,020 m³ ⇒ p₂ = 2493/0,020 = 1,25×10⁵ Pa ≈ 1,25 bar.

A2) Pour un gaz parfait, U dépend de T. Isotherme ⇒ T constante ⇒ ΔU = 0.
Premier principe : ΔU = Q + W ⇒ 0 = Q + W ⇒ Q = −W.

A3) W = −nRT ln(V₂/V₁) = −(1,0×8,31×300) ln(2) = −2493 ln(2).
W ≈ −2493×0,693 ≈ −1,73×10³ J.
Donc Q = −W ≈ +1,73×10³ J (le système reçoit cette chaleur pour rester à 300 K).

A4) ΔSsystème = nR ln(2) = 8,31 ln(2) ≈ 8,31×0,693 ≈ 5,76 J·K⁻¹.

A5) En réversible, l’environnement échange exactement Q à la température T : ΔSenv = −Q/T ≈ −(1,73×10³)/300 ≈ −5,76 J·K⁻¹.
Donc ΔStotal = 0 : signature d’une transformation réversible.

B6) On donne W = −1200 J. Premier principe avec ΔU=0 ⇒ Q = −W = +1200 J.
ΔSsystème ne dépend que des états ⇒ ΔSsystème = nR ln2 ≈ 5,76 J·K⁻¹.
ΔSenv = −Q/T = −1200/300 = −4,00 J·K⁻¹.
ΔStotal = 5,76 − 4,00 = +1,76 J·K⁻¹ > 0 : la détente est irréversible (production d’entropie).
