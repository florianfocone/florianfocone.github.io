Chimie — A) Chimie générale : liaisons, réactions, pH, oxydoréduction

Chimie — A) Chimie générale (bases indispensables)

Définitions
  • Atome : particule constituée d’un noyau (protons + neutrons) et d’électrons autour ; il définit un élément (H, O, Cl…).
  • Molécule : assemblage neutre d’atomes liés (ex : H₂O, CO₂).
  • Ion : atome ou groupe d’atomes chargé (cation + / anion −) après perte/gain d’électrons (ex : Na⁺, Cl⁻, SO₄²⁻).
  • Électron : particule chargée négativement ; les transferts d’électrons expliquent l’oxydoréduction.
  • Liaison covalente : liaison due au partage d’électrons entre atomes (molécules organiques, eau…).
  • Liaison ionique : liaison due à l’attraction entre ions + et − (sels : NaCl…).
  • Polarité : répartition inégale des charges dans une liaison/molécule (ex : H₂O est polaire) ; influence solubilité et réactivité.
  • Réaction chimique : transformation où des réactifs deviennent des produits ; les atomes sont conservés.
  • Équation-bilan : écriture de la réaction ; on ajuste des coefficients pour conserver chaque élément.
  • Quantité de matière (n) : “nombre de moles” ; 1 mol = 6,02×10²³ entités.
  • Concentration molaire (C) : quantité de matière par volume de solution : C = n/V.
  • Réactif limitant : réactif consommé en premier ; il fixe la quantité maximale de produits.
  • Réaction réversible : réaction pouvant se faire dans les deux sens (→ et ←).
  • Équilibre chimique : état d’une réaction réversible où les vitesses directe et inverse sont égales (les quantités deviennent stables).
  • Acide (Brønsted) : espèce qui donne un proton H⁺ (ex : HCl, H₂SO₄).
  • Base (Brønsted) : espèce qui capte un proton H⁺ (ex : NH₃, OH⁻).
  • Couple acide/base : deux espèces ne différant que d’un proton (ex : NH₄⁺/NH₃).
  • Neutralisation : réaction acide + base donnant souvent eau + sel (au moins : H⁺ + OH⁻ → H₂O).
  • pH : nombre qui mesure l’acidité : pH = −log₁₀([H₃O⁺]).
  • Solution acide : pH < 7 ; solution neutre : pH ≈ 7 ; solution basique : pH > 7 (à 25°C, ordre de grandeur).
  • Oxydation : perte d’électrons (ou augmentation du nombre d’oxydation).
  • Réduction : gain d’électrons (ou diminution du nombre d’oxydation).
  • Oxydant : espèce qui capte des électrons (elle se réduit).
  • Réducteur : espèce qui donne des électrons (il s’oxyde).
  • Oxydoréduction : réaction avec transfert d’électrons entre oxydant et réducteur (corrosion, combustion…).
  • Fonction alcool : groupe −OH porté par un carbone (ex : éthanol C₂H₅OH).
  • Fonction aldéhyde : groupe −CHO (carbone terminal) (ex : éthanal).
  • Fonction cétone : groupe >C=O au milieu de chaîne (ex : acétone).
  • Sel : composé ionique (souvent issu acide/base) constitué de cations et d’anions (ex : NaCl, NH₄Cl).
Théorie (zéro base → compréhension rapide)
  • 1) Pourquoi les atomes se lient ? Les atomes “cherchent” une configuration électronique stable. Ils s’assemblent :
    • soit en partageant des électrons → liaison covalente (molécules : eau, hydrocarbures) ;
    • soit en transférant des électrons → ions + et − → liaison ionique (sels : NaCl).
  • 2) Équations et coefficients : dans une réaction chimique, les atomes sont conservés. On ajuste les coefficients pour que chaque élément apparaisse en même nombre dans réactifs et produits.
  • 3) Calculs “moles” (ce qui tombe souvent) :
    • On passe masse → moles avec n = m/M (M = masse molaire).
    • En solution, on utilise n = C·V (V en litres).
    • Le réactif limitant fixe la quantité maximale de produit : c’est celui qui s’épuise en premier quand on suit les proportions de l’équation.
  • 4) Acides, bases et pH :
    • Dans l’eau, un acide augmente la concentration en H₃O⁺ (souvent noté H⁺ en simplifié).
    • Une base augmente la concentration en OH⁻ (ou capte des H⁺).
    • pH est une échelle logarithmique : passer de pH 2 à pH 1 signifie “10 fois plus acide” (10× plus de H₃O⁺).
    • Neutralisation : les ions H⁺ et OH⁻ s’annulent en formant de l’eau ; s’il reste un excès d’acide ou de base, le pH final n’est pas 7.
  • 5) Équilibre chimique (Le Chatelier, version concours) :
    • À l’équilibre, la réaction ne “s’arrête” pas : elle continue dans les deux sens, mais les quantités deviennent stables.
    • Si on perturbe (ajout d’un réactif, retrait d’un produit, changement de température), le système évolue dans le sens qui réduit la perturbation.
  • 6) Oxydoréduction (idée simple) :
    • Les électrons vont du réducteur vers l’oxydant.
    • Exemples terrain : corrosion (oxydation des métaux), combustions (transferts d’électrons vers O₂).
  • 7) Fonctions organiques (pour repérer) :
    • Alcool : présence de −OH (souvent solvants/combustibles).
    • Aldéhyde / cétone : présence de C=O (solvants, odeurs caractéristiques, réactivité spécifique).
Équations pratiques (celles qui servent vraiment)
  • Quantité de matière : n = m/M
  • En solution : n = C·V (V en L)
  • Concentration : C = n/V
  • pH : pH = −log₁₀([H₃O⁺])
  • Neutralisation (simplifiée) : H⁺ + OH⁻ → H₂O
  • Rappel “log” utile : si [H₃O⁺] = 10⁻ᵃ alors pH = a
  • Lettres : n (mol), m (g), M (g·mol⁻¹), C (mol·L⁻¹), V (L), pH (sans unité), [H₃O⁺] (mol·L⁻¹)
Exercice type (acide/base + réactif limitant + pH final)

Sur intervention, on mélange pour neutraliser :
• Va = 200 mL d’acide fort (type HCl) à Ca = 0,50 mol·L⁻¹.
• Vb = 300 mL de base forte (type NaOH) à Cb = 0,20 mol·L⁻¹.
On suppose mélange idéal. Réaction : H⁺ + OH⁻ → H₂O.

1) Calculer n(H⁺) et n(OH⁻). Identifier le réactif limitant.
2) Calculer la quantité de matière de réactif en excès après réaction.
3) En déduire la concentration finale en H₃O⁺, puis le pH final (ordre de grandeur).

Correction :
1) V en L : Va=0,200 L ; Vb=0,300 L.
n(H⁺)=CaVa=0,50×0,200=0,100 mol.
n(OH⁻)=CbVb=0,20×0,300=0,060 mol.
La réaction est 1:1 → OH⁻ est limitant (0,060 < 0,100).

2) Excès d’acide : n(H⁺)exc = 0,100 − 0,060 = 0,040 mol.

3) Volume total Vtot = 0,200 + 0,300 = 0,500 L.
[H₃O⁺] ≈ n(H⁺)exc/Vtot = 0,040/0,500 = 0,080 mol·L⁻¹ = 8×10⁻².
pH = −log(8×10⁻²) = 2 − log 8 ≈ 2 − 0,90 ≈ 1,1.

Lettres : C (mol·L⁻¹), V (L), n (mol), pH.
