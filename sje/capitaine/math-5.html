5 — Nombres complexes : intro, représentation, applications

Définitions
  • Complexe : \(z=a+ib\) avec \(a,b\in\mathbb{R}\) et \(i^2=-1\).
  • Conjugué : \(\overline{z}=a-ib\).
  • Module : \(|z|=\sqrt{a^2+b^2}\).
  • Argument : angle \(\theta\) tel que \(z=|z|(\cos\theta+i\sin\theta)\) (mod \(2\pi\)).
  • Affixe : le complexe \(z\) qui représente un point \(M(a,b)\) du plan.
  • Rotation : multiplication par \(\cos\alpha+i\sin\alpha\) (conserve le module, ajoute \(\alpha\) à l’argument).
Théorie
  • Géométrie : \(z=a+ib\) correspond au point \(M(a,b)\). Le module est une distance et l’argument est un angle.
  • Le conjugué sert à calculer des quotients : on multiplie par \(\overline{z}\) pour obtenir un dénominateur réel.
  • En forme trigonométrique, les produits sont simples : modules se multiplient, arguments s’additionnent.
Équations pratiques
  • \(z\overline{z}=|z|^2=a^2+b^2\)
  • \(\dfrac{1}{a+ib}=\dfrac{a-ib}{a^2+b^2}\) si \(a^2+b^2\neq 0\)
  • Forme trig : \(z=r(\cos\theta+i\sin\theta)\)
  • Produit : \(r_1(\cos\theta_1+i\sin\theta_1)\,r_2(\cos\theta_2+i\sin\theta_2)=r_1r_2(\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2))\)
  • Lettres : \(a,b,r\in\mathbb{R}\), \(r\ge 0\).
Exercice type

Soit \(z=1-i\). 1) Calculer \(|z|\) et \(\overline{z}\). 2) Calculer \(\dfrac{1}{z}\).

Correction :
\(|z|=\sqrt{1^2+(-1)^2}=\sqrt{2}\). \(\overline{z}=1+i\).
\(\dfrac{1}{1-i}=\dfrac{1+i}{(1-i)(1+i)}=\dfrac{1+i}{1-(-1)}=\dfrac{1+i}{2}=\dfrac12+\dfrac{i}{2}\).
\(\boxed{\dfrac{1}{z}=\dfrac12+\dfrac{i}{2}}\).
