Chimie — B) Chimie minérale (corps simples et composés usuels)

Définitions
  • Corps simple : substance faite d’un seul élément chimique (ex : O₂, H₂, C, S, Cl₂).
  • Corps composé : substance contenant plusieurs éléments (ex : H₂O, HCl, H₂SO₄, NH₃, NaOH).
  • Comburant : espèce qui permet/accélère la combustion d’un combustible (ex : O₂).
  • Combustible : espèce qui brûle en présence d’un comburant (H₂, hydrocarbures…).
  • Corrosif : qui attaque la peau/matériaux (acides forts, bases fortes).
  • Oxydant : espèce qui capte des électrons ; souvent favorise réactions violentes.
  • Solution aqueuse : mélange dans l’eau (solvant = eau).
  • Acide fort : libère presque totalement H⁺ dans l’eau (HCl, H₂SO₄).
  • Base forte : libère presque totalement OH⁻ dans l’eau (NaOH).
Théorie (ce qu’il faut retenir, “terrain”)
  • H₂ (dihydrogène) : gaz très léger, très inflammable ; brûle avec O₂ → H₂O ; danger mélange explosif.
  • O₂ (dioxygène) : comburant ; enrichissement en O₂ rend les feux plus violents ; ne “brûle” pas mais alimente la combustion.
  • C (carbone) : en combustion complète → CO₂ ; en manque d’air → CO (toxique) + suies.
  • S (soufre) : brûle en donnant SO₂ (irritant) ; peut contribuer à formation d’acides en présence d’eau/oxydation.
  • Cl₂ (chlore) : gaz toxique/irritant ; réagit avec l’eau → espèces acides/oxydantes ; danger inhalation.
  • F₂ (fluor) : extrêmement réactif/oxydant ; rarement rencontré hors industrie spécialisée ; danger majeur.
  • H₂O (eau) : solvant ; participe aux réactions acide/base (formation H₃O⁺/OH⁻) ; influence corrosion.
  • HCl (acide chlorhydrique) : acide fort, corrosif ; en solution : H⁺ + Cl⁻ ; attaque certains métaux (dégagement possible de H₂).
  • H₂SO₄ (acide sulfurique) : acide fort très corrosif ; peut déshydrater ; mélange avec l’eau : échauffement important (toujours verser l’acide dans l’eau, jamais l’inverse).
  • NH₃ (ammoniac) : gaz basique irritant ; dans l’eau donne une solution basique (NH₄⁺ et OH⁻) ; odeur caractéristique.
  • NaOH (soude) : base forte, très corrosive ; en solution donne Na⁺ et OH⁻ ; attaque graisses (saponification) et tissus.
  • Classification “express” :
    • Gaz (H₂, O₂, NH₃, Cl₂) : risques inhalation, atmosphère explosive/oxydante.
    • Acides forts (HCl, H₂SO₄) : corrosifs, réactions exothermiques, possibles dégagements gazeux.
    • Bases fortes (NaOH) : corrosifs, brûlures chimiques.
Équations pratiques
  • Combustion H₂ : 2 H₂ + O₂ → 2 H₂O
  • Combustion C (complète) : C + O₂ → CO₂
  • Combustion C (incomplète) : 2 C + O₂ → 2 CO
  • HCl en solution : HCl → H⁺ + Cl⁻
  • H₂SO₄ en solution (simplifié) : H₂SO₄ → 2 H⁺ + SO₄²⁻
  • NaOH en solution : NaOH → Na⁺ + OH⁻
  • NH₃ dans l’eau : NH₃ + H₂O ⇌ NH₄⁺ + OH⁻
  • Lettres : coefficients (sans unité), espèces chimiques (formules)
Exercice type (acide fort + neutralisation + sécurité)

On a une solution de HCl : V = 1,0 L à C = 1,0 mol·L⁻¹. On veut neutraliser avec une solution de soude NaOH à Cb = 2,0 mol·L⁻¹.

1) Calculer n(H⁺) contenue dans le bidon (acide fort : [H⁺] ≈ C).
2) Calculer le volume de NaOH nécessaire (H⁺ + OH⁻ → H₂O).
3) Donner une phrase “terrain” : pourquoi on verse l’acide dans l’eau et pas l’inverse ?

Correction :
1) n(H⁺)=C·V = 1,0×1,0 = 1,0 mol.

2) Il faut n(OH⁻)=1,0 mol. Vb=n/Cb=1,0/2,0=0,50 L (500 mL).

3) Mélange eau/acide est exothermique : verser l’eau dans l’acide peut provoquer ébullition locale et projections ; on verse l’acide dans l’eau pour mieux dissiper la chaleur.
